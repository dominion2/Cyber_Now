**Cyber_Now** is a comprehensive laboratory project that bridges the gap between **Cybersecurity Operations** and **Data Science**. This repository showcases automated workflows, predictive modeling for threat detection, and advanced data analytics applied to security landscapes.

## 🚀 Project Overview

The primary mission of this repository is to transform raw security logs and network data into actionable intelligence. By leveraging machine learning and programmatic data pipelines, `Cyber_Now` moves security analysis from reactive monitoring to proactive, data-driven defense.

## 🛠️ Technical Stack

*   **Data Analytics:** SQL (Complex Queries, Schema Design), Advanced Excel (Power Query, ETL).
*   **Data Science:** Python (Pandas, NumPy, Scikit-learn), Statistical Analysis.
*   **Visualization:** Power BI (Interactive Dashboards), Matplotlib, Plotly.
*   **Security Tools:** Nmap (Automated Reconnaissance), NSE (Lua Scripting), Malware Analysis Frameworks.

## 🔍 Key Features

### 1. AI-Powered Threat Detection
*   Implementation of **Logistic Regression** and **MLE** for binary threat classification.
*   Anomaly detection using **Z-score analysis** to identify statistical outliers in system logs.

### 2. Automated Network Intelligence
*   Custom **Python-Nmap** integration for automated network mapping and service discovery.
*   Vulnerability identification through custom **Lua/NSE** scripting.

### 3. Data Pipelines & SQL Optimization
*   Normalization of large-scale security datasets for high-performance retrieval.
*   ETL processes that transition manual spreadsheet tracking into programmatic **Pandas** DataFrames.

### 4. Visual Analytics
*   Translation of complex security event data into **Power BI** dashboards for stakeholder reporting.
*   Visualization of loss landscapes and model performance during training cycles.
