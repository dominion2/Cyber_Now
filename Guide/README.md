# 📚 The Cyber-Data Learning Guide (`/Guide`)

This directory contains the **Knowledge Engine** of the Cyber_Now project. It serves as a structured repository of roadmaps, technical guides, and theoretical frameworks that connect the dots between **Cybersecurity** and **Data Science**.

The resources here are designed to provide the mathematical and technical "why" behind the tools and models found in the other sections of this lab.

## 🗺️ Key Roadmaps

### 1. [Mathematical Foundations for AI](./mathematical-ai-roadmap.md)
*   **Purpose**: A deep dive into the Calculus, Linear Algebra, and Probability required for modern AI.
*   **Highlights**: Neural Network anatomy, Forward/Backward propagation derivations, and the "Semantic Bridge" to embeddings.

### 2. [Database Systems & SQL Optimization](./Database_Systems_Roadmap.md)
*   **Purpose**: A guide to mastering structured data management.
*   **Highlights**: Schema normalization, complex analytical queries (JOINs, CASE), and data integrity for large-scale security logs.

### 3. [Python for Data Science](./Python_for_Data_Science_Roadmap.md)
*   **Purpose**: Technical mastery of the Python analytics stack.
*   **Highlights**: Efficient data manipulation with Pandas/NumPy and transitioning from spreadsheets (Excel) to programmatic pipelines.

## 📖 What You'll Learn Here

*   **Theory to Practice**: How abstract mathematical concepts (like the Chain Rule) manifest in real-world threat detection models.
*   **Data Architecture**: How to structure raw security information for high-performance retrieval and analysis.
*   **Modern AI Workflows**: Understanding the transition from classical statistical models to modern deep learning and LLM architectures.

## 🎯 Educational Philosophy

This guide operates on the principle of **"Applied Rigor."** We don't just use tools; we understand the underlying mathematics and logic to ensure our data-driven security solutions are robust, explainable, and scientifically sound.
