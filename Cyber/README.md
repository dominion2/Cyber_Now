# 🛡️ Cybersecurity Operations Lab (`/Cyber`)

This directory houses the **Operations** side of the Cyber_Now project. While the root repository focuses on Data Science and Analytics, this section is dedicated to the tools, scripts, and methodologies used for **Active Reconnaissance**, **Vulnerability Assessment**, and **Threat Intelligence Gathering**.

The data generated here serves as the primary input for our Machine Learning pipelines and Data Analytics dashboards.

## 🔍 Focus Areas

### 1. Automated Reconnaissance (`/Recon`)
*   **Python-Nmap Automation**: Scripts designed to automate multi-stage network scanning and service discovery.
*   **Custom NSE Scripting**: Integration of Lua scripts via the Nmap Scripting Engine to detect specific misconfigurations and service-level vulnerabilities.
*   **Asset Inventory**: Programmatic generation of network maps for target environment visibility.

### 2. Threat Analysis & Intelligence
*   **Malware Behavioral Analysis**: Tools for monitoring system calls and network traffic generated by potentially malicious artifacts.
*   **Intelligence Feeds**: Collection and parsing of daily security advisories to track emerging CVEs and attack trends.

### 3. Vulnerability Management
*   **Assessment Pipelines**: Workflows for identifying weaknesses in network services and web applications.
*   **Report Generation**: Translating technical scan results into structured formats (JSON/CSV) for downstream data processing.

## 🛠️ Toolset

*   **Languages**: Python 3.x, Lua (NSE).
*   **Core Tools**: Nmap, Wireshark (pcap analysis), OpenSSL.
*   **Libraries**: `python-nmap`, `scapy`, `requests`.

## 🔄 The Data Science Connection

The operations performed in this directory provide the "Raw Data" for the Data Science side of the lab:
1.  **Network Scans** → Feature engineering for **Anomaly Detection**.
2.  **Vulnerability Reports** → Input for **Risk Scoring & Predictive Analytics**.
3.  **Malware Samples** → Training data for **Classification Models**.
